# Hillsborough Dysphagia Atlas

Interactive map of estimated adult dysphagia (swallowing difficulty) across Hillsborough County, Florida.

**Open the map:** https://patil-hemangi.github.io/dysphagia-atlas/

The map shows model-based estimates of risk built from public government data (CDC NHIS 2022, U.S. Census ACS, CDC PLACES, CMS, HRSA). They are not counts of diagnosed cases. Sources, methods and limitations are listed inside the atlas under "Data & methods".
